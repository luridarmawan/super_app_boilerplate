## 🚀 Persiapan untuk build

Sebelum menjalankan aplikasi, copy file konfigurasi berikut:

```bash
# Windows
copy .env.example .env
copy pubspec.yaml.example pubspec.yaml
copy modules.yaml.example modules.yaml
copy android\key.properties.example android\key.properties

# Linux / macOS
cp .env.example .env
cp pubspec.yaml.example pubspec.yaml
cp modules.yaml.example modules.yaml
cp android/key.properties.example android/key.properties
```

Kemudian edit `.env`, `pubspec.yaml`, dan `modules.yaml` sesuai kebutuhan proyek Anda.
`android/key.properties` hanya wajib untuk release build.

> **Penting:** pastikan `ENABLE_MODULE_ARROW_SENSE=true` dan seluruh `ARROW_SENSE_*` terisi di `.env`.
> Tanpa itu modul inti OSA tidak diregistrasi sama sekali.

📚 **Dokumentasi lengkap:** [`docs/Development-and-Build.md`](docs/Development-and-Build.md)

## 🚀 Cara Menjalankan

```bash
# Clone modul eksternal yang terdaftar di modules.yaml (arrow_sense)
dart run tool/sync_modules.dart

# Install dependencies
flutter pub get

# Jalankan di debug mode
flutter run

# Build APK
flutter build apk

# Build iOS
flutter build ios

# Build App Bundle rilis (menaikkan build number lebih dulu)
make build
```
